Lecture Script · Windows 설치판

1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택하세요.
2. 압축을 푼 폴더에서 START-HERE.cmd를 더블클릭하세요.
3. 설치가 끝날 때까지 기다리세요. Python을 따로 설치할 필요가 없습니다.
4. Chrome 확장 관리 화면에서 '개발자 모드'를 켜고
   '압축해제된 확장 프로그램을 로드합니다'를 누르세요.
5. 함께 열린 안내 화면의 '확장 폴더 경로 복사'를 누른 뒤,
   폴더 선택 창의 주소창에 붙여넣고 해당 폴더를 선택하세요.
6. Lecture Script 확장에서 MP4 · MP3 · 스크립트를 선택하고 강의 창을 여세요.

인터넷에 연결된 Windows 10/11 64비트 환경을 위한 설치판입니다.
프로그램은 %LOCALAPPDATA%\LectureScript에 설치됩니다.
Python, pip 패키지, GPU 처리기를 자동으로 준비하며 음성 모델은 첫 사용 때 받습니다.
Chrome이 없다면 Google의 공식 설치 프로그램을 실행합니다. 확인 창이 뜨면 설치를 완료하세요.
Chrome 연결은 자동 등록됩니다. 스토어 미등록 확장 추가는 위의 4~5번을 한 번 직접 해야 합니다.
다시 안내 화면을 열려면 바탕화면의 'Lecture Script - Chrome setup'을 실행하세요.

저장 위치: 다운로드\lecture\과목명\
MP4는 video, MP3는 audio, 스크립트는 script 폴더에 저장됩니다.
처리 중에는 Chrome을 켜두세요. 기본값은 세 항목 모두 선택입니다.
설치 후에는 받은 ZIP과 압축을 푼 폴더를 지워도 됩니다.
%LOCALAPPDATA%\LectureScript는 프로그램 실행에 필요하므로 유지하세요.

설치가 중단되면 인터넷 연결과 오류를 확인하고 START-HERE.cmd를 다시 실행하세요.
설치 기록: %LOCALAPPDATA%\LectureScript\install.log
회사/학교에서 확장 설치를 제한한 Chrome에서는 해당 관리자의 허용이 필요합니다.
