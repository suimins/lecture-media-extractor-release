크롬에 확장 추가

  1. Windows 공유 ZIP은 압축을 전부 풀고 START-HERE.cmd를 실행하세요. Python과 필요한 패키지를 자동으로 설치하고 Chrome 연결을 등록합니다. 설치 후 열리는 Windows 안내에서 확장 폴더 경로를 확인하세요. 소스 폴더에서 바로 사용하려면 setup.cmd를 실행합니다.
  2. Mac·Linux는 Python 3.12를 설치한 뒤, Mac은 setup.command, Linux는 sh setup.sh를 실행합니다.
  3. Mac에서 Metal을 사용하려면 Apple Command Line Tools가 필요합니다. 없다면 xcode-select --install로 설치하고 setup.command를 다시 실행합니다. 실행 권한 오류가 나면 터미널에서 sh setup.command를 사용하세요.
  4. 업데이트한 뒤에는 설치 파일을 다시 실행하고 확장을 새로고침합니다. 폴더만 옮겼다면 Windows는 install-chrome.cmd, Mac은 install-chrome.command로 연결을 다시 등록합니다.
  5. 크롬 주소창에 chrome://extensions를 입력합니다.
  6. 오른쪽 위 개발자 모드를 켭니다.
  7. 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  8. 이 프로젝트 안의 extension 폴더를 선택합니다.
  9. 확장 아이콘을 누르고 MP4 영상 · MP3 음성 · 스크립트 중 저장할 항목을 체크합니다. 기본값은 모두 선택입니다.
  10. 크롬에서 한성 eClass에 로그인한 뒤, 과목 페이지에서 강의 동영상 창을 엽니다.

영상 주소가 감지되면 체크한 파일을 자동으로 저장합니다. 재생을 눌러야 주소를 제공하는 영상은 한 번 재생하세요. 수동으로 시작하려면 선택한 파일 다운로드 / 재시도를 누릅니다.

이미 열려 있던 과목·동영상 페이지는 확장 설치 후 새로고침하세요. 진행 상황은 확장 아이콘을 누르면 볼 수 있습니다.

체크한 항목만 생성하며 선택한 결과물은 그대로 보존합니다. 완료되면 임시 영상·WAV·작업 파일만 정리합니다. 실패·중단된 작업의 파일과 로컬 원본은 보존합니다. 과목명을 찾지 못하면 과목 미지정에 저장되며 확장에서 과목명을 입력할 수 있습니다.

선택은 다음 실행에도 유지됩니다. 완료한 강의를 다시 열면 현재 선택한 결과가 모두 있을 때 기존 파일을 사용합니다. 선택을 추가하거나 파일이 없으면 다시 처리하고, 앞서 저장한 결과물은 유지합니다.

사용 중

처리 중에는 크롬을 켜두세요. 확장 팝업이나 강의 탭은 닫아도 처리가 이어집니다. 크롬을 종료하면 중단되며, 같은 강의를 다시 열면 완료한 단계부터 이어서 처리합니다.

스크립트를 해제하면 음성 인식을 생략합니다. MP4만 선택하면 음성 추출도 생략합니다. 최소 한 항목을 선택해야 시작할 수 있습니다.

자동 실행은 한성 eClass 동영상 창에 적용됩니다. 다른 사이트에서는 선택한 파일 다운로드 / 재시도를 누릅니다. DRM 영상은 지원하지 않습니다.

Windows는 start.cmd, Mac은 start.command로 기록 확인과 내 파일 변환 화면을 엽니다. 자동 저장에는 이 창을 켜둘 필요가 없습니다.

GPU 자동 사용

Windows에서는 CUDA·Vulkan, Mac에서는 Metal, Linux에서는 Vulkan을 자동으로 확인합니다. 제조사 이름만으로 판단하지 않고 실제 장치 감지와 짧은 추론을 통과한 GPU를 사용합니다. Apple Silicon과 Intel Mac 모두 Metal을 확인하며, 사용할 수 없으면 CPU로 전환합니다.

전사 중 GPU (CUDA), GPU (VULKAN), GPU (METAL) 또는 CPU가 표시됩니다. 선택한 모델 크기는 유지하며 영상 저장·MP3 변환 단계에서는 GPU 사용량이 낮을 수 있습니다.

플랫폼별 실행 조건과 배포 출처는 README에서 확인할 수 있습니다.
